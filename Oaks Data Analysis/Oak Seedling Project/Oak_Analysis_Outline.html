By applying a Shapiro-Wilk test we see that the data is not normally distributed (p = 0.008). Nontheless, use of the Bartlett test demonstrates that the data is roughly equal in variance across treatment types (p = 0.599). We must use a non-parametric test; in this case the Kruskal-Wallis test.
