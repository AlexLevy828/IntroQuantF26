Exploratory Data Analysis:

Before you can analyze your specific questions, you need to clean up and get a sense of the data. Exploratory Data Analysis has the following goals:

  1. Generate questions about your data.

    1. This is not just about your research questions! Questions might include: how many samples are there for each treatment? Why is there a weird outlier in that one variable? Why won’t this variable plot?

    2. More interesting questions might include: Is there a relationship between these variables? Why is there a pattern where one is higher in only that variable?

  2. Search for answers by visualizing, transforming, and modelling your data.

    1. You can identify problems (like outliers or NA values) by plotting data, or transforming and manipulating it. Answers might include: That outlier was entered incorrectly from the original datasheets, OR it keyed to the wrong species; This variable won’t plot because R originally read it in as a character instead of a number (and some lines had words entered instead of NA). Data Cleaning

How to Examine and Clean Data

In this section we will look at and clean up each of the data sets you identified that you would like to analyze in your research questions. What to look for when data cleaning:

  1. Dimensions
    1. Does the data have the right number of rows? Are there blank rows of NAs at the bottom that need to be removed?
      • nrow(), dim(), glimpse() to view counts of rows
    2. Do you have all the columns you need? Do you need to bring in additional information for context?
      • ncol(), str(), names(), glimpse() to view column numbers and names
      • full_join(), inner_join(), left_join() etc. to merge with other data based on matching columns
      • Are there columns you won’t use that you’d like to exclude for simplicity using select()
  2. Column names
    1. Are your column names tidy (i.e., have no punctuation or spaces, consistent capitals)?
      • rename() to fix column names
      • Recommendation: rename some of those messy LICOR columns to more useful and memorable ones!
  3. Data types
    1. Are your columns in the correct format?
      • typeof(data$variable) or glimpse() to check column data type
      • mutate(variable = as.numeric()) to convert to numeric
      • mutate(variable = as.character()) to convert to string/word
      • mutate(variable = factor()) to convert to factor
    2. Do the values in your columns all match the format you want? (e.g., are there characters in a numeric column?
      • unique(data$variable) to see all unique values in that column
      • mutate(variable = case_when([see Data Wrangling demo])) to repair
    3. Are there any cells that contain two kinds of information and may need to be separated? (e.g. Tag_Num that also includes sapling A/B or A1, A2, or A3)
      • separate() to create two new columns by splitting the data based on a delimiter
  4. Irregular Values
    1. Do all the values make sense for your data set (e.g., outliers)
      1. summary(df$variable) gives the min & max and other values to see IF there is a weird value
      2. which(df$variable == 102.0) gives the ROW NUMBER of any rows that have that value
      3. If you find something weird, check it against the original data sheets, correct or remove with filter() if appropriate.
      4. View your data with histograms.

#clean data
Moist_Data <- Moist_Data_Raw |>
  
  #Remove rows without data
  filter(Treatment != "NA") |>
  
  #Convert VWC values of 0.0 to be NA
  mutate(VWC1_perc = case_when(
    VWC1_perc == "0.0" ~ NA, 
    VWC1_perc != "0.0" ~ VWC1_perc)) |>
  
  mutate(VWC2_perc = case_when(
    VWC2_perc == "0.0" ~ NA, 
    VWC2_perc != "0.0" ~ VWC2_perc)) |>
  
  mutate(VWC3_perc = case_when(
    VWC3_perc == "0.0" ~ NA, 
    VWC3_perc != "0.0" ~ VWC3_perc)) |>
  
  #remove rows that do not include VWC data
  filter(VWC1_perc != "NA") |>
  
  #remove columns that do not include data relavent for my analysis
  select(Date, Block, Treatment, VWC1_perc, VWC2_perc, VWC3_perc) |>

  #change VWC  and date data into numeric values
  mutate(VWC1_perc = as.numeric(VWC1_perc)) |>
  mutate(VWC2_perc = as.numeric(VWC2_perc)) |>
  mutate(VWC3_perc = as.numeric(VWC3_perc)) |>
  
#add average VWC as new column
  rowwise()|>
  
  mutate(VWC = mean(c(VWC1_perc, VWC2_perc, VWC3_perc), na.rm = TRUE))
